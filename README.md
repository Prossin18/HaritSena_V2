# Harit Sena 🌱

Harit Sena is a full-stack Django web application that promotes sustainable waste management by connecting citizens with waste collectors. It provides secure authentication, waste pickup requests, admin management, and an eco-reward system.

## Tech Stack

- Python
- Django
- HTML
- CSS
- Bootstrap
- JavaScript
- SQLite
- Git & GitHub
